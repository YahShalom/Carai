# Atelier AI Demo Showcase

A premium AI demo showcase platform built with Next.js App Router, TypeScript, TailwindCSS, and Framer Motion.

## Local Development

1. Install dependencies:
   `npm install`
2. Start the app:
   `npm run dev`
3. Open `http://localhost:3000`

## Production Build

- `npm run build`
- `npm run start`

## Demo Routes

- `/demo-apps`
- `/demo-apps/fashion-stylist`
- `/demo-apps/barber-vision`
- `/demo-apps/atelier-concierge`

## Notes

- The site uses a luxury dark UI, glassmorphism, animated interactions, and premium AI demo storytelling.
- `app/demo-apps/data/demoApps.ts` contains centralized demo data for the platform.
